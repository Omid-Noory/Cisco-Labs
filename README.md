# Cisco Labs

A collection of hands-on Cisco networking labs built with Cisco Packet Tracer.

These labs focus on practical networking, configuration, troubleshooting, and problem-solving.

## Labs

### 1. Inter-VLAN Routing Troubleshooting Challenge

A practical troubleshooting lab involving:

- VLAN configuration
- Access ports
- Switched Virtual Interfaces (SVIs)
- IP addressing
- Inter-VLAN routing
- Layer 3 switching
- Network troubleshooting

## Tools

- Cisco Packet Tracer
- Cisco IOS CLI

## Goal

The goal of these labs is to strengthen my networking skills through hands-on configuration and troubleshooting rather than theory alone.

More labs coming soon.
